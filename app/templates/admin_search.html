数据边界（重要）

  • 发出去的只有检索词：提问会先摘掉日期、邮箱、链接，再过一遍外发策略； 命中姓名、站点专属词等敏感内容时直接放弃联网，不会猜测或改写后发送。
  • 发回来的是公开网页：抓到的正文作为「依据」连同来源 URL 一起给模型， 回复里必须写明来源；这些内容会随该次问答进入你配置的模型端点。
  • 抓取失败会明说：扫描件、需要登录的页面、纯 JS 渲染页拿不到正文时， 助手会告诉用户「没查到外部资料」，而不是编一个答案。
  • 健康档案本身不会发给 Hyperbrowser：只发检索词，不发档案、不发照片。

为什么不用官方 SDK

这台服务器只有 961MB 内存（应用自己占 81MB）。实测在本机：

方式额外内存额外磁盘结论
标准库 urllib 直连 REST（当前实现）00采用
官方 Python SDK（hyperbrowser）+35.9MB（import 即发生，httpx+pydantic）约 7MB不需要
官方 Node SDK（@hyperbrowser/sdk）+40.8MB（一个 Node 进程，与主应用不共享）约 90MB（Node 运行时）+ 依赖更重，还要装 Node

我们只用两个接口（/api/web/search 与 /api/web/fetch）， 用标准库发 JSON 请求即可，省下的内存留给应用本身。
