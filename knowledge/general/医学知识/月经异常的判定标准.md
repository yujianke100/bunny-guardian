# 月经异常的判定标准

> 本文用于回答一个具体问题：**什么样的情况算"月经异常"，以及通常在什么时机需要就医。**
>
> 说明：本资料**不涉及任何药物名称与剂量**。所有判定标准与阈值均在句末标注来源链接（`[来源: <URL>]`）；凡未能从可访问的权威来源核实的数字或说法，一律不写入正文，另见文末"未核实与存疑事项"。
>
> 判定原则：正常月经的四个要素为**周期频率、规律性、经期长度、经期出血量**，其中任何一项偏离正常范围、且出血源自子宫腔，即构成"异常子宫出血（abnormal uterine bleeding, AUB）"这一总术语 [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide] [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/abnormal-uterine-bleeding/abnormal-uterine-bleeding]。

相关文档：[[docs/医学知识/月经周期生理与正常范围.md|月经周期生理与正常范围]]（正常值基线）、[[docs/医学知识/症状自查与就医指引.md|症状自查与就医指引]]（红旗症状与就医时机）、[[docs/医学知识/常见妇科疾病档案.md|常见妇科疾病档案]]（AUB 各病因的疾病条目）。

## 1. 基线：正常月经的参数范围

判定的前提是先知道"正常"长什么样。不同权威来源给出的正常值略有差异，以下并列列出。

| 参数 | 国际（FIGO/MSD） | 中国指南术语表 | 来源 |
|---|---|---|---|
| 周期频率 | 每 24–38 天一次 | 28±7 天（即 21–35 天） | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 规律性（最短–最长周期差） | 年龄相关：18–25 岁 ≤9 天；26–41 岁 ≤7 天；42–45 岁 ≤9 天（可简记为 ±4 天） | 近 1 年周期之间变化 <7 天为规律 | [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 经期长度 | 4.5–8 天（≤8 天为正常） | 正常 3–7 天 | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 经期出血量 | 5–80 mL | 5–80 mL | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |

- 一个常被引用的简化表述：正常月经周期为 24–38 天，经期持续 2–7 天，失血量 5–80 mL；这四项中任何一项偏离即构成 AUB [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/]。
- FIGO 2018 修订版把"规律性"的判定改为年龄相关的 7–9 天波动范围，替代了 2011 版"最短到最长相差可达 20 天"的旧定义 [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666]。
- FIGO 建议**废弃** menorrhagia（月经过多）、metrorrhagia（子宫出血）、oligomenorrhea、dysfunctional uterine bleeding（功血）等定义模糊的旧术语，改用统一的新术语体系 [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide]。

## 2. 异常子宫出血（AUB）的定义与两种病程

- **AUB 总定义**：与正常月经的周期频率、规律性、经期长度、经期出血量中**任何一项不符**、且源自子宫腔的异常出血；限定于育龄期非妊娠妇女，不包含青春发育前与绝经后出血 [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide] [来源: https://sdhmdplib.yuntsg.com/ueditor/jsp/upload/file/20190412/1555052257138000577.pdf]。
- **慢性 AUB**：出血在持续时间、量、频率和/或规律性上异常，且已存在于**此前 6 个月中的大部分时间**（FIGO）；中国指南表述为"近 6 个月内至少出现 3 次 AUB，医师认为不需要紧急临床处理、但需进行规范诊疗" [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide]。
- **急性 AUB**：一次出血量大到（在临床医师判断下）需要**立即干预**以避免或减少进一步失血；可发生在慢性 AUB 背景之上，也可独立出现 [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2013/04/management-of-acute-abnormal-uterine-bleeding-in-nonpregnant-reproductive-aged-women]。
- 评估任何一个 AUB 患者时，第一优先事项是判断**出血是否重到需要急诊处理**、以及**患者是否可能怀孕** [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding]。

## 3. 病因分类：FIGO 的 PALM-COEIN 九大类

FIGO 用两个系统描述这一主题：**System 1** 是症状（出血模式）的命名与定义，**System 2** 是病因分类（PALM-COEIN）。PALM 属"结构性"（可经影像和/或组织病理识别），COEIN 属"非结构性" [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666]。

| 缩写 | 类别 | 一句话说明 | 来源 |
|---|---|---|---|
| **P** | 子宫内膜息肉（Polyp） | 子宫内膜或宫颈管的局灶性赘生物，可无症状，也可引起经间期出血 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] | |
| **A** | 子宫腺肌病（Adenomyosis） | 子宫内膜组织位于子宫肌层内，常伴经量多、经期长、痛经和子宫增大 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] | |
| **L** | 子宫平滑肌瘤（Leiomyoma，肌瘤） | 良性平滑肌肿瘤，较大或黏膜下者可引起经量多或经期长，许多肌瘤无症状 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] | |
| **M** | 子宫内膜恶变与不典型增生（Malignancy and hyperplasia） | 子宫内膜增生与癌，常表现为不可预测的出血；危险因素为无孕激素对抗的长期雌激素暴露 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] | |
| **C** | 全身凝血相关疾病（Coagulopathy） | 系统性出血性疾病（如血管性血友病）是经量多的常见原因，尤其在青少年和年轻女性中 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] | |
| **O** | 排卵障碍（Ovulatory dysfunction） | 无排卵或稀发排卵导致月经稀发、不规则、量多或经期长，是 AUB 最常见的原因（约占 50%）[来源: https://cmab.yiigle.com/uploads/guide_html/%E6%8E%92%E5%8D%B5%E9%9A%9C%E7%A2%8D%E6%80%A7%E5%BC%82%E5%B8%B8%E5%AD%90%E5%AE%AB%E5%87%BA%E8%A1%80%E8%AF%8A%E6%B2%BB%E6%8C%87%E5%8D%97.html] | |
| **E** | 子宫内膜局部异常（Endometrial） | 有排卵、规律周期下，因内膜局部止血/修复机制异常引起的异常出血，需排除其他原因后诊断 [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide] | |
| **I** | 医源性（Iatrogenic） | 由激素类药物、宫内节育器/缓释系统、抗凝药或手术损伤（如宫腔粘连）等引起的出血 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] | |
| **N** | 未分类（Not otherwise classified） | 少见或定义不清的病因，如子宫动静脉畸形、慢性子宫内膜炎、剖宫产瘢痕缺损等 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] | |

- 2018 修订版仍为九大类；原"AUB-C"中与药物（抗凝等）相关的出血被重新归入"AUB-I" [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666]。
- 一名患者可同时存在一个或多个病因，诊断可写成"异常子宫出血—子宫肌瘤，排卵障碍"这样的多病因表达 [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide]。

## 4. 按出血模式分类的定义与阈值

### 4.1 频率、规律性、长度、量的异常

| 出血模式 | 阈值/定义 | 国内指南用词 | 来源 |
|---|---|---|---|
| 闭经（Amenorrhea） | 育龄女性无月经；FIGO 以 90 天无出血为参照 [来源: https://pmc.ncbi.nlm.nih.gov/articles/PMC10086853/] | 中国术语表：≥6 个月无月经 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 月经频发 | 周期 <21 天（中国）/ <24 天（FIGO 频率"frequent"） | 月经频发 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] [来源: https://www.msdmanuals.cn/professional/gynecology-and-obstetrics/abnormal-uterine-bleeding/abnormal-uterine-bleeding] |
| 月经稀发 | 周期 >35 天（中国）；FIGO 频率"infrequent">38 天 | 月经稀发 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] |
| 不规律月经 | 近 1 年周期之间变化 ≥7 天（中国）；FIGO 2018 将"不规则"量化为 ≥8–10 天 | 不规律月经 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] |
| 月经过多（HMB） | 经期出血量 >80 mL；或"出血量多到影响身体、社会、情绪和/或物质生活质量"（NICE 定义，FIGO 采用） | 月经过多 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] |
| 月经过少 | 经期出血量 <5 mL | 月经过少 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 经期延长 | 经期 >7 天（中国）；FIGO 以 >8 天为"prolonged" | 经期延长 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] |
| 经期过短 | 经期 <3 天 | 经期过短 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |

- HMB 是一种**症状而非诊断**，其核心判定是"是否影响到生活质量"，而非必须精确测出 80 mL [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666]。
- FIGO 将任何偏离月经参数第 5–95 百分位的出血定义为"不规则出血"；2018 版补充：偶尔一次偏长或偏短的周期不应算作不规则 [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666]。

### 4.2 闭经：原发性与继发性

| 类型 | 定义 | 来源 |
|---|---|---|
| 原发性闭经 | 至 15 岁仍无月经（且已有正常第二性征发育）；或乳房发育后 3 年（乳蕾出现在 10 岁前则为 5 年）仍无月经 | [来源: https://www.ncbi.nlm.nih.gov/books/NBK482168] [来源: https://www.asrm.org/practice-guidance/practice-committee-documents/current-evaluation-of-amenorrhea] |
| 继发性闭经 | 既往月经规律者停经 **≥3 个月**（或 ≥3 个周期）；既往月经不规律者停经 **≥6 个月** | [来源: https://www.ncbi.nlm.nih.gov/books/NBK482168] [来源: https://www.ncbi.nlm.nih.gov/books/NBK431055] |
| 需提前评估的情况 | 13 岁仍无乳房发育（无论有无月经）应评估青春期延迟 | [来源: https://www.ncbi.nlm.nih.gov/books/NBK482168] [来源: https://www.acog.org/womens-health/faqs/amenorrhea-absence-of-periods] |

- ACOG 的表述：无论年龄，只要月经**无解释地停止 3 个月以上**即应接受评估 [来源: https://www.acog.org/womens-health/faqs/amenorrhea-absence-of-periods]。
- 无避孕措施、有性生活的育龄女性，闭经**首先要排除妊娠**；停经即使只有 1 周也可能需要排除妊娠 [来源: https://www.asrm.org/practice-guidance/practice-committee-documents/current-evaluation-of-amenorrhea] [来源: https://www.ncbi.nlm.nih.gov/books/NBK431055]。

### 4.3 经间期出血（IMB）与突破性出血（BTB）

- **经间期出血（IMB）**：发生在月经之间、自发性的出血，可为周期性（每个周期固定时间）或随机；中国指南定义为"有规律、在可预期的月经之间发生的出血"，按出血时间可分为卵泡期出血、围排卵期出血、黄体期出血 [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide] [来源: https://cmab.yiigle.com/uploads/guide_html/%E6%8E%92%E5%8D%B5%E9%9A%9C%E7%A2%8D%E6%80%A7%E5%BC%82%E5%B8%B8%E5%AD%90%E5%AE%AB%E5%87%BA%E8%A1%80%E8%AF%8A%E6%B2%BB%E6%8C%87%E5%8D%97.html]。
- **突破性出血（BTB）**：使用激素类避孕制剂过程中出现的计划外子宫内膜出血；出血量多者为"bleeding"，量少者为"spotting（点滴出血）"；它是医源性 AUB（AUB-I）的主要原因 [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide] [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g]。
- 宫内节育器引起的经期延长，可能与局部前列腺素生成过多或纤溶亢进有关；首次使用含孕激素宫内缓释系统者，6 个月内亦常发生 BTB [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide]。
- NICE 提示：持续存在的经间期出血提示可能存在子宫腔或子宫内膜病变，是进一步的宫腔检查（宫腔镜）或子宫内膜评估的指征之一 [来源: https://www.nice.org.uk/guidance/ng88/chapter/Recommendations]。

## 5. 可直接使用的判定表格（症状 → 阈值 → 术语 → 就医时机）

> "就医时机"一列是**基于指南建议的通常做法**，用于帮助判断轻重缓急，不能替代个体化临床判断。

| 症状 / 发现 | 判定阈值 | 对应术语 | 通常建议的就医时机 | 来源 |
|---|---|---|---|---|
| 月经间隔过短 | 周期 <21 天 | 月经频发 | 反复出现时安排妇科门诊评估 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 月经间隔过长 | 周期 >35 天（>38 天更明确） | 月经稀发 | 持续或加重、或伴闭经趋势时就诊 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] |
| 周期忽长忽短 | 近 1 年周期之间变化 ≥7 天 | 不规律月经 | 门诊评估病因（常与排卵障碍相关） | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 月经停止 | 原发：15 岁仍无月经；继发：≥3 个月（曾规律）/ ≥6 个月（曾不规律） | 闭经 | 无解释停经 >3 个月即应就诊；有性生活者先排除妊娠 | [来源: https://www.ncbi.nlm.nih.gov/books/NBK482168] [来源: https://www.acog.org/womens-health/faqs/amenorrhea-absence-of-periods] |
| 经期拖得很长 | 经期 >7 天（FIGO >8 天） | 经期延长 | 反复出现时门诊评估 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] |
| 经期过短 | 经期 <3 天 | 经期过短 | 视是否影响生育等需求决定是否就诊 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 经量过多 | >80 mL/周期，或出血影响到生活质量 | 月经过多（HMB） | 就诊；所有 HMB 女性建议查血常规评估贫血 | [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666] [来源: https://www.nice.org.uk/guidance/ng88/chapter/Recommendations] |
| 经量过少 | <5 mL/周期 | 月经过少 | 视伴随症状（闭经、不孕等）决定就诊 | [来源: https://drugs.dxy.cn/pc/clinicalDecision/pdVhB3viFNd_kqK1A_KHR4g] |
| 两次月经之间出血 | 任何量的经间期出血 | 经间期出血（IMB） | 持续存在时就诊，需评估宫腔/内膜病变 | [来源: https://www.nice.org.uk/guidance/ng88/chapter/Recommendations] |
| 用药期间计划外出血 | 任何量 | 突破性出血（BTB） | 反复或量多时就诊，评估用药相关因素 | [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide] |
| 性交后出血 | 任何量 | 性交后出血 | 尽快就诊（需排除宫颈病变） | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| 绝经后出血 | 末次月经后 >12 个月出现任何出血 | 绝经后出血 | 立即就诊，必须排除子宫内膜癌 | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| 痛经进行性加重 / 治疗无改善 | 经验性治疗 3–6 个月无效，或疼痛逐月加重 | 继发性痛经（警惕子宫内膜异位症） | 就诊，考虑进一步影像或专科评估 | [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis] |
| 经前情绪/躯体症状 | 见第 7 节 | PMS / PMDD | 症状影响工作或人际关系时就诊 | [来源: https://www.acog.org/clinical/clinical-guidance/clinical-practice-guideline/articles/2023/12/management-of-premenstrual-disorders] |

## 6. 不同年龄段的判定差异

### 6.1 青春期（初潮后数年）

- 初潮后第 1 个妇科年内平均周期约 32.2 天，周期区间通常为 **21–45 天**；经期 ≤7 天；日用卫生巾/棉条约 3–6 片 [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2015/12/menstruation-in-girls-and-adolescents-using-the-menstrual-cycle-as-a-vital-sign]。
- 青少年持续无月经超过 **3 个月（90 天）**在统计学上属少见（相当于周期的第 95 百分位），应引起注意 [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2015/12/menstruation-in-girls-and-adolescents-using-the-menstrual-cycle-as-a-vital-sign]。
- 青春期 AUB 的最常见原因是**下丘脑–垂体–卵巢轴尚未成熟，导致无排卵或稀发排卵**；但经量多的青少年也要筛查**凝血障碍**（出血性疾病约占因经量多就诊的青春期女孩的 20%）[来源: https://cmab.yiigle.com/uploads/guide_html/%E6%8E%92%E5%8D%B5%E9%9A%9C%E7%A2%8D%E6%80%A7%E5%BC%82%E5%B8%B8%E5%AD%90%E5%AE%AB%E5%87%BA%E8%A1%80%E8%AF%8A%E6%B2%BB%E6%8C%87%E5%8D%97.html] [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2019/09/screening-and-management-of-bleeding-disorders-in-adolescents-with-heavy-menstrual-bleeding]。
- 青少年经量多应评估贫血（含血清铁蛋白）、导致无排卵的内分泌疾病和出血性疾病；**不建议仅为排查经量多而常规做超声**，除非初始处理无效 [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2019/09/screening-and-management-of-bleeding-disorders-in-adolescents-with-heavy-menstrual-bleeding]。
- 初潮即出现经量多，或伴既往拔牙/术后/产后出血史、家族出血史，是提示凝血障碍的重要线索 [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2019/09/screening-and-management-of-bleeding-disorders-in-adolescents-with-heavy-menstrual-bleeding]。

### 6.2 育龄期（生育年龄）

- 育龄期任何异常生殖道出血，**首先做妊娠试验**，即使病史不提示妊娠；异位妊娠等妊娠相关出血可危及生命 [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding]。
- 有排卵者通常周期频率与规律性正常，但可能出现经量过多或经间期出血；无排卵（AUB-O）者则表现为闭经或时间不规则的出血，量可多可少 [来源: https://www.msdmanuals.cn/professional/gynecology-and-obstetrics/abnormal-uterine-bleeding/abnormal-uterine-bleeding]。
- 育龄期无排卵的常见病因包括多囊卵巢综合征、肥胖、高催乳素血症、甲状腺疾病等，常表现为月经不规律，有时引起大出血和重度贫血 [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide]。

### 6.3 围绝经期与绝经后

- 围绝经期 AUB 最常见于排卵障碍，但**子宫内膜病变（增生、癌）的风险随年龄升高**，必须警惕 [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/abnormal-uterine-bleeding/abnormal-uterine-bleeding] [来源: https://pmc.ncbi.nlm.nih.gov/articles/PMC3702059/]。
- **子宫内膜取样（活检）指征**：所有 ≥45 岁的 AUB 患者，以及 <45 岁但有持续无排卵/无孕激素对抗的雌激素暴露史、持续出血或治疗无效者 [来源: https://www.aafp.org/afp/2019/0401/p435] [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/]。中国指南亦将"年龄 ≥45 岁、长期不规律子宫出血、有子宫内膜癌高危因素、药物疗效不满意"列为诊刮/宫腔镜活检的指征 [来源: https://cmab.yiigle.com/uploads/guide_html/%E6%8E%92%E5%8D%B5%E9%9A%9C%E7%A2%8D%E6%80%A7%E5%BC%82%E5%B8%B8%E5%AD%90%E5%AE%AB%E5%87%BA%E8%A1%80%E8%AF%8A%E6%B2%BB%E6%8C%87%E5%8D%97.html]。
- **绝经后出血**（末次月经后 >12 个月出现的出血）属异常，需进一步评估以排除子宫内膜癌；不服用外源性激素者最常见的病因是内膜萎缩，但仍须排除增生或癌 [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding]。
- 围绝经期不应再将"盲刮"作为唯一诊断手段，宫腔镜直视下取样能发现更多病变 [来源: https://pmc.ncbi.nlm.nih.gov/articles/PMC3702059/]。

## 7. 痛经的分类与需要警惕的表现

### 7.1 分类

- **原发性痛经**：有痛经但**无盆腔器质性病变** [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis]。
- **继发性痛经**：由盆腔器质性疾病或已确诊的疾病所致的痛经；在青少年中，**子宫内膜异位症是继发性痛经的首要原因** [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis]。
- 痛经是青少年和年轻女性最常见的月经相关症状；多数为原发性，对经验性治疗反应良好 [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis]。

### 7.2 需要警惕继发性痛经的表现

出现以下任一项时，应怀疑继发性痛经并进一步评估：

- 初潮后不久即出现**严重的痛经**，或痛经**进行性加重** [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis]。
- 合并**异常子宫出血**（经量多和/或不规则出血）、经中期或非周期性（acyclic）疼痛 [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis]。
- **对经验性治疗无反应**（治疗 3–6 个月仍无改善）[来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis]。
- 合并不孕、性交痛，或有子宫内膜异位症家族史（一级亲属患病者风险升高 7–10 倍）[来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis]。
- 疼痛影响到日常活动、生活质量，或导致缺课、缺勤 [来源: https://www.ncbi.nlm.nih.gov/books/NBK536044/]。
- 周期性（经期相关）的**肠道症状**（尤其排便痛）或**泌尿症状**（尤其血尿、排尿痛），或深部性交痛/性交后疼痛——需警惕深部子宫内膜异位症 [来源: https://www.ncbi.nlm.nih.gov/books/NBK536044/]。
- 慢性盆腔痛（持续或周期性疼痛 ≥6 个月）[来源: https://www.ncbi.nlm.nih.gov/books/NBK536044/]。
- 若疑诊深部子宫内膜异位症累及肠、膀胱或输尿管（如双侧卵巢子宫内膜异位囊肿、周期性排便痛等），应转诊至专科中心 [来源: https://www.ncbi.nlm.nih.gov/books/NBK536044/]。

> 注意：正常盆腔检查或正常超声**不能排除**子宫内膜异位症 [来源: https://www.ncbi.nlm.nih.gov/books/NBK536044/]。

## 8. 经前期综合征（PMS）与经前焦虑障碍（PMDD）的判定标准

### 8.1 PMS（经前期综合征）

ACOG 的判定要点：

- 症状需**在月经前的 5 天内出现，并连续至少 3 个月经周期如此** [来源: https://www.acog.org/womens-health/faqs/premenstrual-syndrome]。
- 症状需在**月经开始后 4 天内缓解**，且在**排卵前的卵泡期有一段无症状期** [来源: https://www.acog.org/womens-health/faqs/premenstrual-syndrome] [来源: https://www.ncbi.nlm.nih.gov/books/NBK519704/table/ch3.t24/]。
- 症状需**干扰到部分日常活动**（社交、工作等可识别的功能受损）[来源: https://www.acog.org/womens-health/faqs/premenstrual-syndrome]。
- 症状应出现于**未使用药物/激素**的状态下 [来源: https://www.ncbi.nlm.nih.gov/books/NBK519704/table/ch3.t24/]。
- 公认的 PMS 诊断应有**前瞻性每日症状记录**（至少 2 个连续周期）来确认症状的周期性 [来源: https://www.acog.org/clinical/clinical-guidance/clinical-practice-guideline/articles/2023/12/management-of-premenstrual-disorders]。
- 诊断前需排除其他可在经前加重的疾病（抑郁、焦虑、甲状腺疾病、围绝经期、慢性疲劳等）[来源: https://www.acog.org/womens-health/faqs/premenstrual-syndrome]。

### 8.2 PMDD（经前焦虑障碍）——DSM-5 标准

| 条目 | 内容 |
|---|---|
| **A. 时间性** | 在**大多数月经周期**中，至少 5 个症状出现在月经前的最后 1 周，月经开始后几天内开始改善，月经后 1 周内基本消失或缺失 [来源: https://www.ncbi.nlm.nih.gov/books/NBK279045/table/premenstrual-syndrom.table1diag/] |
| **B. 核心情感症状（≥1 项）** | ① 显著情绪不稳（情绪波动、突然悲伤或流泪、对拒绝敏感）；② 显著易激惹/愤怒或人际冲突增加；③ 显著抑郁情绪、绝望感或自我贬低；④ 显著焦虑、紧张或"紧绷/坐立不安" [来源: https://www.ncbi.nlm.nih.gov/books/NBK279045/table/premenstrual-syndrom.table1diag/] |
| **C. 附加症状（与 B 合计达 5 项）** | 兴趣减退；注意力困难；乏力/易疲劳/明显缺乏精力；食欲改变（暴食或强烈食物渴求）；嗜睡或失眠；感觉不堪重负或失控；躯体症状（乳房胀痛或肿胀、关节或肌肉痛、"腹胀"或体重增加）[来源: https://www.ncbi.nlm.nih.gov/books/NBK279045/table/premenstrual-syndrom.table1diag/] |
| **D. 功能损害** | 症状带来**临床显著的痛苦**，或干扰工作、学业、日常社交或人际关系 [来源: https://www.ncbi.nlm.nih.gov/books/NBK279045/table/premenstrual-syndrom.table1diag/] |
| **E. 确认方式** | 上述 A–C 需在**过去 1 年的大多数月经周期**中满足；且标准 A 应由至少 2 个症状周期的**前瞻性每日评分**确认（此前可作临时诊断）[来源: https://www.ncbi.nlm.nih.gov/books/NBK519704/table/ch3.t24/] |

- PMDD 可视为 PMS 的严重形式，特点是症状显著干扰工作、学业或人际关系 [来源: https://www.acog.org/womens-health/faqs/premenstrual-syndrome]。
- 提示需要就医：症状影响到工作或人际关系时，应考虑就医评估 [来源: https://www.acog.org/clinical/clinical-guidance/clinical-practice-guideline/articles/2023/12/management-of-premenstrual-disorders]。

## 9. 红旗症状清单：建议立刻就诊 / 急诊

出现以下任一项，应尽快就诊或直接前往急诊，而不是"再观察一个周期"：

| 红旗症状 | 为什么需要立刻处理 | 来源 |
|---|---|---|
| **大量阴道出血**：每 1–2 小时就浸透一片卫生巾/一条棉条、排出大血块、或伴头晕/眼前发黑/乏力感 | 提示出血量大，可能造成贫血、血流动力学不稳定甚至休克 | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| **血流动力学不稳定**的表现：站立时头晕、心率快、血压下降、意识改变 | AUB 急性发作需先评估生命体征并紧急处理 | [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2013/04/management-of-acute-abnormal-uterine-bleeding-in-nonpregnant-reproductive-aged-women] |
| **可能怀孕情况下的出血**：有性生活/避孕失败/停经后出血/伴恶心、乳房胀痛 | 未识别的妊娠相关出血（尤其异位妊娠）可危及生命，必须先排除妊娠 | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| **急性下腹痛**，尤其突发单侧疼痛、发生在月经中期或性交时 | 可能提示卵巢囊肿破裂等急症 | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| **发热 + 盆腔/下腹痛 + 阴道异常分泌物** | 需警惕盆腔炎性疾病（PID） | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| **性交后出血** | 需排除宫颈病变（包括宫颈癌） | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| **绝经后出血**（末次月经后 >12 个月出现的任何出血） | 需排除子宫内膜癌等恶性病变 | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] |
| **长期无排卵样出血 + 肥胖/多囊/糖尿病等**（无孕激素对抗的雌激素暴露） | 子宫内膜增生与癌的风险升高，需评估子宫内膜 | [来源: https://www.aafp.org/afp/2019/0401/p435] [来源: https://www.ncbi.nlm.nih.gov/books/NBK532913/] |
| **重度贫血征象**：面色苍白、活动后气促、心悸、异食癖等 | 慢性大量月经失血是缺铁性贫血的常见原因，需评估与纠正 | [来源: https://www.msdmanuals.com/professional/gynecology-and-obstetrics/symptoms-of-gynecologic-disorders/vaginal-bleeding] [来源: https://www.msdmanuals.cn/professional/gynecology-and-obstetrics/abnormal-uterine-bleeding/abnormal-uterine-bleeding] |
| **自幼/初潮起即经量多，且伴鼻衄、拔牙或术后出血、家族出血史** | 提示可能存在凝血障碍，需筛查 | [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2019/09/screening-and-management-of-bleeding-disorders-in-adolescents-with-heavy-menstrual-bleeding] |
| **痛经进行性加重，或伴性交痛/排便痛/不孕** | 需警惕子宫内膜异位症等继发性病因 | [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2018/09/dysmenorrhea-and-endometriosis] [来源: https://www.ncbi.nlm.nih.gov/books/NBK536044/] |
| **经前症状严重到影响工作、学业或人际关系，或有自伤/失控感** | 提示可能为 PMDD，需要专业评估 | [来源: https://www.acog.org/clinical/clinical-guidance/clinical-practice-guideline/articles/2023/12/management-of-premenstrual-disorders] |

**一般性原则**：出现红旗症状按急诊处理；不属红旗但满足"异常"阈值的情况，通常建议在**1 个周期内**或**症状持续存在时**安排妇科门诊评估；急性 AUB 是指出血量大到需要立即干预的情形 [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666]。

## 10. 快速自查：把观察变成判据

1. **记录要素**：每个周期记下——本次月经第 1 天、下次月经第 1 天（算周期长度）、出血持续天数、每天卫生用品更换频次、是否有点滴出血/经间期出血、疼痛程度及对生活的影响 [来源: https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2015/12/menstruation-in-girls-and-adolescents-using-the-menstrual-cycle-as-a-vital-sign]。
2. **至少观察 3 个周期**再下"规律/不规律"的结论；偶尔 1 次偏长或偏短不算不规则 [来源: https://obgyn.onlinelibrary.wiley.com/doi/full/10.1002/ijgo.12666]。
3. **对照第 5 节表格**判断属于哪一种出血模式。
4. **同时核对第 9 节红旗清单**：命中任一条 → 立刻就诊/急诊。
5. **就医时带上记录**：病史（尤其近 3 次出血的时间与特点）是判断 AUB 模式与病因的第一步 [来源: https://test.pmphai.com/jeesitede/appguide/toPcDetail?id=0001AA100000000EGD5O&knowledgeLibPrefix=guide]。
