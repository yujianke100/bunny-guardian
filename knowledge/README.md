# knowledge/ —— 通用知识（随软件分发）

这里放的是**通用**医学知识：不含任何个人信息，体积较大，删掉随时可以拿回来。
它与个人数据仓库（`KB_DIR`，默认 `~/kb`）严格分开：

```
knowledge/general/          ← 本目录：通用知识，随代码仓走（公开）
<数据目录>/kb-general/       ← 部署时展开到本地，服务实际读取的位置（不进任何 git）
<KB_DIR>/docs/              ← 个人知识 + 记录（私人数据仓库，单独备份与同步）
```

服务启动时两层一起导入数据库，检索时不分层。导出回数据仓库时**只导出个人层**，
通用知识不会被同步带进私人仓库。

## 目录约定

`knowledge/general/` 下的子目录名要与数据仓库里的一致（如 `医学知识/`），
这样同一篇文档的相对路径在两层都相同，重复导入只会更新归属层，不会产生重复条目。

## 本地副本被删了怎么办

重跑安装脚本即可补齐（脚本只补缺失文件，不覆盖你本地改过的内容）：

```bash
sh deploy/install.sh --no-deps
```
