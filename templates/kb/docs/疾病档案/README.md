# 疾病档案

按「一种疾病 = 一份档案」的方式归档，每份档案下挂一条**病程时间线**（就诊、检查、用药、手术、症状变化）。

## 字段

| 层级 | 字段 |
|---|---|
| 档案 | 名称、分类、状态（治疗中/随访观察/已痊愈）、起病时间、确诊时间、医院、科室、医师、概述 |
| 病程事件 | 日期、类型、标题、详情、结果/结论 |
| 附件 | 检查单、报告照片（jpg/png/pdf，≤12MB，保存在服务器本地，不进入 git 仓库） |

## 生成的文件

| 文件 | 内容 |
|---|---|
| [[疾病列表]] | 所有疾病的清单、状态与事件数 |
| 每种疾病一个文档 | 基本信息 + 概述 + 病程事件表 |

## 使用建议

- 确诊后就建立档案，之后每次复查追加一条事件，避免纸质量表散落。
- 对照 [[常见妇科疾病档案]] 了解该疾病的常用检查与判断依据；对照 [[症状自查与就医指引]] 判断就医时机。

> 本目录内容仅供健康管理参考，不能替代医生面诊、检查与诊断。
