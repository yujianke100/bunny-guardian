# 就医记录

按就诊次数记录：时间、机构、科室、医师、就诊原因、检查所见、诊断、处置医嘱、费用。

## 生成的文件

| 文件 | 内容 |
|---|---|
| [[就诊记录]] | 历次就诊的完整表格 |

## 就诊前建议准备

- 本次及近 3 个月的周期起止日期（见 [[周期统计]]）
- 出血量与疼痛评分、伴随症状的变化过程
- 正在使用的药物与保健品清单
- 既往检查报告（对照 [[检查项目与参考值]] 看指标含义）

> 本目录内容仅供健康管理参考，不能替代医生面诊、检查与诊断。
