# 经期记录

记录月经周期与每日症状，供周期统计、阶段推断与就医准备使用。

## 记录字段

| 字段 | 说明 |
|---|---|
| 月经记录 | 一次月经的开始日期、结束日期、经量（少/中/多）、症状、备注 |
| 每日日志 | 日期、类型（症状/疼痛/情绪/经量变化/点滴出血/用药/基础体温/体重/备注）、名称、程度 1–5、数值、备注 |

## 生成的文件

| 文件 | 内容 |
|---|---|
| [[周期记录]] | 历次月经的起止、经量、症状 |
| [[周期统计]] | 周期长度统计（中位数/范围/标准差）与下次经期、阶段推断 |

## 统计方法说明

- 周期长度取**近 6 次间隔的中位数**，同时给出最小/最大值与标准差作为波动区间。
- 阶段划分：月经期（经期长度内）→ 卵泡期 → 排卵期（估算排卵日前后各 1 天）→ 黄体期；
  估算排卵日 = 预计下次月经日 − 14 天（黄体期相对稳定的生理学近似）。
- **全部预测均为统计推断**，不是检测结果，不能用于避孕、备孕决策或疾病诊断。

> 本目录内容仅供健康管理参考，不能替代医生面诊、检查与诊断。
