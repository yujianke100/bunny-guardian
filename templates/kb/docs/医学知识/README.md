# 医学知识

本目录收录**带来源**的医学知识整理，用于理解指标、判断就医时机，以及和医生沟通时做准备。

## 阅读须知

- 本目录内容**不能替代医生面诊、检查与诊断**，也不构成用药建议。
- 每篇文档中的事实性陈述都以 `[来源: URL]` 标注出处；未找到可靠来源的内容会标为「（待核实）」，不作为结论。
- 参考范围以化验单标注为准（不同实验室区间不同）。
